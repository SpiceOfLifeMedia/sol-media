How to install (60 seconds):
1. Click anywhere in the white box below.
2. Press Cmd+A (Mac) or Ctrl+A (Windows) to select all.
3. Press Cmd+C / Ctrl+C to copy.
4. Go to Outlook → ⚙️ Settings → Mail → Compose and reply → Email signature.
5. Click in the signature editor box and paste with Cmd+V / Ctrl+V.
6. Tick "Set default for new messages" and "Set default for replies and forwards".
7. Hit Save at the bottom. That's it.
